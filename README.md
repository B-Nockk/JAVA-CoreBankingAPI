# JAVA-CoreBankingAPI

Production-grade core banking REST API (Java 25 + Spring Boot 4.0.3)

## Tech Stack

- Java 25 (Temurin)
- Spring Boot 4.0.3
- Spring Data JPA + H2 (dev) / PostgreSQL (prod)
- Lombok + Bean Validation
- JUnit 5 + Mockito
- Structured logging (Logback)

## Skills Demonstrated

- REST APIs with proper layering
- JPA entities + repositories
- DTOs + validation
- Global exception handling
- Unit + integration tests
- Clean logging + configuration

## Quick Start

## Quick Start Commands (recommended)

```bash
make dev-up      # starts persistent Postgres
make dev-logs    # watch DB (optional)
./mvnw spring-boot:run   # start Spring Boot
```

**API runs on `http://localhost:8080`**
